# Student Performance Analysis

## Project Overview
This project analyzes student marks using Python and data analytics techniques.

## Objectives
- Calculate total and average marks.
- Identify the top-performing student.
- Compare subject-wise performance.
- Calculate pass and fail counts.
- Visualize results using graphs.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Project Workflow
1. Created a dataset of 10 students.
2. Checked missing values and duplicate records.
3. Calculated total and average marks.
4. Classified students as Pass or Fail.
5. Created three graphs for visualization.
6. Generated findings from the data.

## Conclusion
This project helped me learn basic data cleaning, analysis, and visualization.
